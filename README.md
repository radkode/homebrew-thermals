# Thermals Homebrew tap

Installs Thermals, a menu bar app that shows how hot your Mac is running, with CPU load, per-core and per-app usage. Apple Silicon, macOS 14 or later.

```sh
brew install --cask radkode/thermals/thermals
```

Update with `brew upgrade --cask thermals`.

Release archives are signed with a Developer ID and notarized. They are published here as GitHub Releases by the release script in the Thermals source repository, which also updates `Casks/thermals.rb`.
